# NerdQaxe++ → FreeCash Solo

| Feld | Wert |
|------|------|
| Stratum Host | NAS- oder PC-IP |
| Stratum Port | 3333 |
| Username | `Fxxxxxxxx…yyyy.nerdq1` |
| Password | `x` oder `d=256` |

- Adresse **muss** mit `F` beginnen (FreeCash).
- Kein `bitcoincashii:` Prefix – das ist BCH2 und hier falsch.
- Fallback optional: Mining-Dutch FCH SOLO, solange lokaler Node sync.
